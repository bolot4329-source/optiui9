# UltraCore 2.0

Системный комбайн для **любого Android-смартфона** (Android 15, 16, 17 и новее) на Shizuku, без Root. APK собирается в GitHub Actions. Подробное ТЗ — в `docs/TZ.md`.

- **Главная** — телефон, режим Shizuku и список «что работает на этом телефоне»; оптимизация системы.
- **Файлы** — очистка мусора с предпросмотром и сортировка файлов с откатом.
- **Приложения** и **Терминал** — в разработке (фазы 3–5).

## Как получить APK

1. Открой репозиторий на GitHub → вкладка **Actions**.
2. Выбери последнюю сборку «Build UltraCore APK» с зелёной галочкой (новая стартует сама после каждого изменения, идёт ~3–8 минут).
3. Внизу страницы, в разделе **Artifacts**, скачай `UltraCore-Debug` (это zip, внутри APK).

## Первый запуск на телефоне

1. Установи и запусти **Shizuku** (через «Беспроводную отладку»). После перезагрузки телефона Shizuku нужно запускать заново.
2. Установи APK из архива, открой UltraCore.
3. «Shizuku» → **Разрешить** → подтверди в окне Shizuku.
4. «Доступ к файлам» → **Выдать доступ к файлам** → включи переключатель → вернись назад.
5. На вкладке **Главная → Обзор** появится список возможностей: ✅ работает, ⚠️ частично, 🔒 недоступно (с причиной).
6. Кнопка **Тест Shell** покажет `uid=2000(shell)` (или `uid=0` при Root), версию Android и номер прошивки.

Если какой-то пункт 🔒 с подсказкой про ограничения отладки — в «Для разработчиков» поищи дополнительные переключатели отладки (у некоторых производителей есть второй переключатель «Отладка по USB (настройки безопасности)»), а в настройках безопасности — функции, блокирующие USB/ADB-команды.

Если сборка в Actions упала — открой упавший шаг, скопируй последние ~50 строк лога и пришли.

## Заметки
- Debug-сборки подписываются ключом `app/ultracore-debug.keystore` из репозитория, поэтому новые версии ставятся поверх старой без удаления. Не удаляй этот файл.
- `gradlew` в проекте нет: в облаке Gradle 8.10.2 ставится экшеном `setup-gradle`.
