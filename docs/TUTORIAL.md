## 1. Что это за приложение

**UltraCore** — набор инструментов для обслуживания телефона в одном приложении. Он умеет то, что обычные приложения не могут: менять скрытые системные настройки, замораживать встроенные приложения, чистить системные папки и выполнять команды Android.

Для этого не нужен Root (взлом телефона). UltraCore получает расширенные права через бесплатное приложение **Shizuku** — примерно такие же, как у компьютера, подключённого к телефону по кабелю для отладки.

**Что можно делать:**

| Задача | Где в приложении |
|---|---|
| Узнать износ батареи, циклы зарядки, температуру | Главная → Батарея |
| Ускорить анимации, закрепить частоту экрана 120 Гц | Главная → Твики |
| Очистить кэш и «разогнать» систему в одно касание | Главная → Оптимизация |
| Найти и удалить мусор, дубликаты, остатки удалённых приложений | Файлы → Очистка |
| Разложить файлы из «Загрузок» по папкам | Файлы → Сортировка |
| Открыть скрытые экраны настроек и вынести их ярлыком на рабочий стол | Приложения → Экраны |
| Заморозить или убрать ненужные встроенные приложения | Приложения → Управление |
| Сделать копию APK любого приложения | Приложения → Управление |
| Держать редкие приложения «спящими» и будить по ярлыку | Приложения → Управление → Песочница |
| Выполнять команды Android и запускать их одной кнопкой из шторки | Терминал |

**Главная идея:** приложение работает на любом телефоне — Samsung, Xiaomi, Pixel, OnePlus, Honor и других. Оно само проверяет, что разрешено именно на вашем телефоне, и честно показывает это значками:

- ✅ — работает;
- ⚠️ — работает частично (с пояснением);
- 🔒 — недоступно на этом телефоне (с причиной: например, «нужен Root»).

## 2. Безопасно ли это

UltraCore получает серьёзные права, поэтому в нём много защит:

- **Ничего не удаляется без вашего подтверждения.** Сначала показывается, что будет сделано, и только потом выполняется.
- **Важные части системы защищены 🛡.** Рабочий стол, «Телефон», SMS, клавиатуру, «Настройки», системный интерфейс, Shizuku и сам UltraCore заморозить или удалить нельзя.
- **Почти всё обратимо.** Твики сбрасываются кнопкой «Сбросить», замороженные приложения размораживаются, удалённые системные приложения восстанавливаются, перемещённые файлы возвращаются на место. Подробнее — в разделе [Как всё вернуть назад](#12-как-всё-вернуть-назад).
- **Важные системные папки** (DCIM, Download, Android и другие) удалить нельзя.
- **Команды не выполняются на заблокированном телефоне** — плитка в шторке сначала попросит разблокировать экран.
- **Ярлыки защищены подписью** — чужое приложение не может подделать ярлык UltraCore.

Чего всё же стоит избегать новичку:

- не замораживать и не удалять системные приложения, если не знаете, за что они отвечают;
- не выполнять в Терминале команды из непроверенных источников;
- не включать «Разрешить откат версии» при установке, если не понимаете зачем.

## 3. Что понадобится

- Android-смартфон на **Android 12 или новее** (лучше 15+).
- Приложение **Shizuku** (бесплатно, Google Play или GitHub).
- **Wi-Fi** — нужен только для запуска Shizuku без компьютера (интернет не обязателен, достаточно подключения к любой сети Wi-Fi).
- Файл **UltraCore** (APK).

## 4. Установка Shizuku (один раз)

Shizuku — посредник, который выдаёт UltraCore расширенные права. Настраивается один раз, но **после каждой перезагрузки телефона Shizuku нужно запускать заново** (это 20 секунд).

### Шаг 1. Включите режим разработчика

1. Откройте **Настройки → О телефоне** (на некоторых телефонах ещё → **Сведения о ПО** или **Версия ПО**).
2. Найдите строку **Номер сборки** (на Xiaomi — **Версия ОС**).
3. Нажмите на неё **7 раз подряд**. Появится сообщение «Вы стали разработчиком».

### Шаг 2. Включите отладку по Wi-Fi

1. Откройте **Настройки → Параметры разработчика** (обычно в самом низу настроек или в разделе «Система» / «Дополнительно»).
2. Включите **Отладка по USB**.
3. Включите **Отладка по Wi-Fi** (Wireless debugging). Телефон должен быть подключён к Wi-Fi.

> **Xiaomi / Redmi / POCO:** включите ещё **«Отладка по USB (настройки безопасности)»** — без неё многие функции будут 🔒. Для этого пункта нужен вход в Mi-аккаунт.
>
> **Samsung:** если включён **«Автоблокировщик»** (Настройки → Безопасность и конфиденциальность), он может блокировать команды. При проблемах временно отключите его.

### Шаг 3. Запустите Shizuku

1. Установите и откройте **Shizuku**.
2. В разделе «Запуск через беспроводную отладку» нажмите **Сопряжение** (Pairing). Shizuku покажет уведомление.
3. Откройте **Параметры разработчика → Отладка по Wi-Fi → Подключить устройство с помощью кода**. Появится 6-значный код.
4. Опустите шторку и введите этот код **в уведомление Shizuku**.
5. Вернитесь в Shizuku и нажмите **Запустить**. Через несколько секунд появится надпись «Shizuku работает».

Сопряжение делается один раз. После перезагрузки телефона достаточно открыть Shizuku и нажать **Запустить** (Wi-Fi и отладка по Wi-Fi должны быть включены).

## 5. Установка UltraCore

1. Скачайте APK:
   - откройте страницу проекта на GitHub → вкладка **Actions**;
   - выберите последнюю сборку **«Build UltraCore APK»** с зелёной галочкой ✅;
   - внизу страницы, в разделе **Artifacts**, скачайте **UltraCore-Debug** (это zip-архив);
   - распакуйте его — внутри файл APK.
2. Откройте APK. Если телефон спросит — разрешите установку из этого источника.
3. Обновления ставятся **поверх старой версии**, удалять предыдущую не нужно (настройки и данные сохранятся).

## 6. Первый запуск

Вверху экрана — **карточка состояния**. Пока что-то не настроено, она развёрнута.

1. **Shizuku → «Разрешить».** Появится окно Shizuku — нажмите «Разрешить всегда».
   - Если окно не появилось: откройте Shizuku → **Приложения** и включите UltraCore вручную.
   - Если написано «Не установлен» — кнопка откроет страницу загрузки Shizuku.
   - Если «Не запущен» — откройте Shizuku и нажмите «Запустить» (см. раздел 4).
2. **Доступ к файлам → «Выдать доступ к файлам».** Включите переключатель и вернитесь назад. Это нужно для очистки и сортировки файлов.
3. По желанию нажмите **«Тест Shell»** — должно появиться `uid=2000(shell)`, версия Android и номер прошивки. Значит, всё работает.

Когда всё готово, карточка сворачивается в одну строку: `Shizuku · ADB, без Root`. Нажмите на неё, чтобы раскрыть снова.

> **ADB, без Root** — обычный режим. **Root** появится, только если Shizuku запущен на телефоне с Root-правами: тогда станут доступны функции с 🔒 «нужен Root».

## 7. Как устроено приложение

Внизу четыре вкладки, внутри некоторых — подвкладки сверху:

```
Главная     →  Обзор | Батарея | Твики | Оптимизация
Файлы       →  Очистка | Сортировка
Приложения  →  Экраны | Управление
Терминал    →  Консоль | Команды | Макросы
```

Общие правила интерфейса:

- **🔄 Обновить** — перечитать данные.
- **Сбросить** (жёлтая кнопка) — вернуть исходное значение.
- Красные кнопки и надписи — действия, которые что-то удаляют или меняют; перед ними всегда спрашивается подтверждение.
- Если что-то не получилось, приложение показывает **причину простыми словами** и исходный текст ошибки.

## 8. Главная

### 8.1. Обзор — «Что работает на этом телефоне»

Здесь видно модель телефона, версию Android, номер прошивки и режим Shizuku.

Ниже — список возможностей с итогом `✅ 8 ⚠️ 0 🔒 2`. Под каждым пунктом написано, где эта возможность используется (например, «Приложения → Управление»). Если что-то 🔒, рядом объяснено почему.

- Проверка **ничего не меняет** на телефоне.
- Запускается автоматически при первом подключении Shizuku и после обновления системы.
- Кнопка 🔄 — проверить заново.

> **Совет:** если видите 🔒 с подсказкой про ограничения отладки — загляните в «Параметры разработчика» (у некоторых производителей есть второй переключатель отладки) и в настройки безопасности (функции блокировки USB/ADB-команд).

### 8.2. Батарея — паспорт батареи

Крупно — уровень заряда и состояние (заряжается / разряжается, от сети / USB / беспроводная).

**Паспорт батареи:**

| Показатель | Что значит |
|---|---|
| Температура | Нормально 20–40 °C. Выше 45 °C — телефон перегревается |
| Напряжение | Текущее напряжение батареи, мВ |
| Состояние | Оценка системы: Хорошее / Перегрев / Изношена и т. д. |
| Циклы зарядки | Сколько полных циклов «0→100 %» прошла батарея |
| Здоровье батареи | Остаточная ёмкость в %. 100 % — как новая, ниже 80 % — заметный износ |
| Заряд сейчас | Сколько мАч в батарее в данный момент |
| Оценка полной ёмкости | Примерная реальная ёмкость (показывается при заряде от 20 %) |
| Ток | Минус — батарея разряжается, плюс — заряжается |

Справа от каждого значения — **источник**:
- **Android** — стандартные данные системы (самые надёжные);
- **dumpsys / sysfs** — данные прошивки производителя;
- **расчёт** — оценка, сделанная UltraCore.

Внизу — **«Дополнительные данные от прошивки»**: всё, что ваш телефон сообщает о батарее сверх стандарта, как есть. Полезно опытным пользователям.

Данные обновляются каждые 5 секунд; кнопка 🔄 — обновить сразу.

### 8.3. Твики — быстрые настройки системы

У каждого твика есть **«Сбросить»** — она возвращает значение, которое было **до первого изменения** в UltraCore.

**Скорость анимаций** — `выкл. / 0.5x / 1x`.
- **0.5x** — интерфейс ощущается заметно быстрее. Рекомендуем.
- **выкл.** — анимаций нет совсем, всё мгновенно.
- **1x** — стандарт.

**Частота экрана** — кнопки только с частотами, которые реально поддерживает ваш экран (например, 60 / 120 Гц).
- Выбранная частота **закрепляется** — экран не будет её снижать.
- После применения UltraCore проверяет, что экран действительно переключился. Зелёное сообщение — всё работает. Жёлтое — ваша прошивка управляет частотой своей настройкой; тогда выберите режим в системном меню «Дисплей».
- Постоянные 120 Гц расходуют больше заряда.

**Ограничение фоновых процессов** — Android 12+ принудительно закрывает «лишние» фоновые процессы, из-за чего могут обрываться терминалы и долгие задачи. Кнопка **«Отключить ограничение»** снимает этот лимит. Нужна в основном опытным пользователям.

### 8.4. Оптимизация

Сверху — память телефона, ОЗУ и файл подкачки, обновляются каждые 3 секунды.

**«Полная оптимизация» → «Запустить в 1 тап»** — одна кнопка, которая по очереди:
1. очищает кэш приложений;
2. освобождает оперативную память (закрывает фоновые процессы);
3. очищает системные журналы и запускает TRIM (обслуживание памяти);
4. перекомпилирует приложения для более быстрой работы (ART-компиляция).

Каждый шаг можно запустить и отдельно (раздел «Инструменты»). Компиляция может идти несколько минут — её можно прервать кнопкой «Остановить». Внизу — консоль выполненных команд.

> Оптимизацию достаточно делать раз в несколько недель или после крупного обновления системы.

## 9. Файлы

### 9.1. Очистка

1. Нажмите **«Сканировать»**. UltraCore ищет:
   - **остатки удалённых приложений** в Android/data и Android/obb (папки приложений, которых уже нет на телефоне);
   - **миниатюры** (.thumbnails) — их система создаст заново при необходимости;
   - **временные файлы и логи** (*.log, *.tmp, *.temp);
   - **пустые папки**;
   - **дубликаты** файлов больше 1 МБ (сравниваются по содержимому, самая старая копия сохраняется).
2. Просмотрите найденное по категориям, раскройте списки, отметьте то, что хотите удалить.
3. Нажмите **«Удалить»** и подтвердите. Внимание: удаление файлов **отменить нельзя** — смотрите внимательно, особенно дубликаты.

Сканирование само по себе ничего не удаляет. Важные системные папки никогда не попадают в список.

### 9.2. Сортировка

Автоматически раскладывает файлы по папкам по **правилам**. Уже есть готовые правила для папки «Загрузки» (Download): установщики APK → `Download/Installers`, документы → `Documents/Downloads/pdf` (папка по расширению), картинки → `Pictures/Downloads/2026/10` (по году и месяцу), видео и т. д.

1. Посмотрите и при желании измените **правила** или добавьте **«Новое правило»**: папка-источник, расширения файлов и целевая папка. В целевой папке можно использовать шаблоны `{yyyy}` — год, `{MM}` — месяц, `{dd}` — день, `{ext}` — расширение. Перебираются только файлы в самой папке-источнике (без вложенных папок).
2. Нажмите **«Предпросмотр (Dry Run)»** — появится план: какой файл куда переедет. **Ничего ещё не перемещено.**
3. Если всё устраивает — **«Выполнить»**.
4. Передумали? В **«Журнале операций»** нажмите **«Откатить»** — файлы вернутся на место, созданные пустые папки удалятся. Хранятся 20 последних операций.
5. Испортили правила? **«Сбросить»** вернёт стандартный набор.

Существующие файлы никогда не перезаписываются: при совпадении имён добавляется « (1)».

## 10. Приложения

### 10.1. Экраны — запуск скрытых экранов приложений

У каждого приложения есть «экраны» (Activity). Многие из них не видны в обычном меню — например, скрытые разделы настроек.

1. Найдите приложение поиском (по названию, имени пакета или названию экрана) или выберите фильтр: **Пользовательские / Все / Системные / Закрытые экраны**.
2. Нажмите на приложение — раскроется список его экранов.
3. У каждого экрана подписано, как он откроется:
   - 🟢 **открывается напрямую**;
   - 🟡 **защищён разрешением — через Shizuku**;
   - 🔴 🔒 **закрытый экран — нужен Root**: без Root Android такой экран не откроет;
   - **отключён** — экран выключен самим приложением.
4. Кнопки справа:
   - ▶ — открыть экран;
   - ☆ — добавить в **Избранное** (появится наверху списка);
   - 📲 — **создать ярлык на рабочем столе**: телефон спросит подтверждение, потом экран открывается с рабочего стола одним касанием.

> **Пример:** найдите `com.android.settings` → там десятки разделов настроек, в том числе тех, до которых сложно добраться через меню.

> Если ярлык перестал работать после обновления UltraCore — удалите его и создайте заново.

### 10.2. Управление — заморозка, удаление, бэкап, установка

**Фильтры:** Пользовательские · Системные · Замороженные · Удалённые · Песочница. Сверху — поиск, 🔄 обновить и ⬇ **установить APK**.

Значки у приложений:
- **❄ заморожено** — приложение выключено, не запускается и не тратит ресурсы;
- **удалено** — системное приложение удалено для пользователя (можно вернуть);
- **песочница** — приложение в песочнице;
- **🛡 защищено** — важная часть системы, заморозить или удалить нельзя.

**Действия с одним приложением** — нажмите на него:

| Действие | Что делает | Как вернуть |
|---|---|---|
| ❄ Заморозить | Выключает приложение: пропадает с рабочего стола, не работает в фоне | «Разморозить» |
| В песочницу | Замораживает, но позволяет быстро открыть по ярлыку (см. ниже) | «Убрать из песочницы» |
| Бэкап APK | Сохраняет файл приложения в `Download/UltraCore/Backups` | — |
| Удалить для пользователя | Только для **системных** приложений: убирает их у вас, но файл остаётся в системе | Фильтр «Удалённые» → «Восстановить» |
| Открыть в настройках телефона | Системная страница приложения | — |

**Несколько приложений сразу** — отметьте галочки слева. Внизу появится панель: **Заморозить · Разморозить · Бэкап APK · Удалить для пользователя** (во вкладке «Удалённые» — **Восстановить**). После выполнения покажется отчёт: что получилось и что нет — с причиной.

> **Обычные (не системные) приложения** UltraCore не удаляет — для этого есть стандартное удаление Android, оно надёжнее.

**Бэкап APK.** Приложения, состоящие из нескольких частей (так устроены многие современные приложения из Google Play), сохраняются архивом **.apks**. Его можно установить обратно через UltraCore.

**Установка APK** — кнопка ⬇ справа от поиска:
1. Выберите файл **.apk**, **.apks** или **.xapk**.
2. Опции (обычно не нужны):
   - **Разрешить откат версии** — установить более старую версию поверх новой. Экспериментально: без Root Android обычно это запрещает;
   - **Указать установщик Google Play** — включайте, только если прошивка блокирует установку.
3. Нажмите **«Установить»** и дождитесь сообщения.

### 10.3. Песочница — «спящие» приложения

Песочница нужна для приложений, которыми вы пользуетесь редко (банк для одного платежа в месяц, магазин, игра). Они **заморожены всё время** и не тратят батарею, но открываются как обычно.

**Как пользоваться:**
1. Нажмите на приложение → **«В песочницу»**. Оно сразу заморозится.
2. Нажмите на него ещё раз → **«Ярлык песочницы на рабочий стол»**.
3. Открывайте приложение этим ярлыком (или кнопкой «Открыть из песочницы»): UltraCore разморозит и запустит его.
4. Когда вы **выключите экран**, через выбранное время приложение снова заморозится. Если включите экран раньше — заморозка отменится.

**Настройки** (фильтр «Песочница»):
- **Задержка заморозки:** сразу / 30 с / 2 мин. 30 секунд — чтобы случайное нажатие кнопки питания не закрыло приложение с несохранёнными данными.
- **«Разрешить уведомление песочницы»** — пока приложения разморожены, в шторке висит тихое уведомление. Оно нужно Android, чтобы песочница работала в фоне.
- **«Отключить экономию батареи для UltraCore»** — обязательно сделайте это (и для Shizuku тоже), иначе прошивка может остановить песочницу в фоне.

> Если Shizuku отключился, когда приложение было разморожено, оно заморозится автоматически при следующем запуске Shizuku (но только при выключенном экране — чтобы не закрыть его, пока вы им пользуетесь).

## 11. Терминал

Терминал выполняет команды Android с правами Shizuku. Новичку не обязательно что-то писать вручную — есть готовый каталог.

### 11.1. Консоль

- Введите команду внизу и нажмите ➤ (или «Отправить» на клавиатуре).
- Вывод появляется **в реальном времени**, строка за строкой.
- **Стоп** — остановить команду (например, бесконечный лог).
- Кнопки под окном: 📋 скопировать весь вывод, ⬇ сохранить в файл .txt, 🗑 очистить.
- Над полем ввода появляются **подсказки из истории** — нажмите, чтобы подставить.

Цвета: голубой — ваша команда, белый — ответ, жёлтый — служебные сообщения, красный — ошибки.

> Команды выполняются от имени системного пользователя `shell`. Интерактивные программы, которые ждут ввода с клавиатуры, не поддерживаются.

### 11.2. Команды — готовый каталог

34 полезные команды по разделам: **Система, Сеть, Батарея, Дисплей, Приложения, Диагностика**. У каждой — понятное описание.

1. Нажмите на команду.
2. Если нужны данные (например, имя приложения или адрес сервера) — заполните поле.
3. **«Выполнить»** — сразу запустить; **«В консоль»** — подставить в консоль, чтобы поправить перед запуском.

Команды с пометкой **«изменяет»** что-то меняют в системе (например, «Очистить данные приложения» удаляет ВСЕ данные приложения) — перед ними дополнительное предупреждение.

**Полезные для начала:**
- *Система → Свободное место* — сколько памяти занято;
- *Батарея → Кто не даёт уснуть* — что держит телефон бодрствующим и разряжает батарею;
- *Диагностика → Последние сбои* — какие приложения падали;
- *Диагностика → Живой лог* — журнал в реальном времени (остановите кнопкой «Стоп»).

> **Как узнать имя пакета приложения?** Приложения → Управление → найдите приложение — имя пакета (вида `com.example.app`) написано под названием.

### 11.3. Макросы — несколько команд одной кнопкой

Макрос — список команд, которые выполняются по очереди. Если какая-то завершится с ошибкой, следующие не выполняются.

- **+ Новый макрос** — введите название и команды, **по одной в строке**.
- ▶ **Запустить** — перед запуском показывается список команд для подтверждения; вывод идёт в Консоль.
- ✏ изменить, 🗑 удалить.
- ☆ **звёздочка** — этот макрос будет запускаться **плиткой в шторке**.

Для примера уже есть макрос «Диагностика» (версия Android, уровень заряда, свободное место).

### 11.4. Плитка «Макрос» в шторке

1. Отметьте нужный макрос звёздочкой ★.
2. Опустите шторку полностью → нажмите ✏ (карандаш / «Изменить») → найдите плитку **«Макрос»** (UltraCore) → перетащите её к активным плиткам.
3. Теперь нажатие на плитку запускает макрос **без открытия приложения**; результат появится всплывающим сообщением.

На заблокированном телефоне плитка сначала попросит разблокировать экран.

## 12. Как всё вернуть назад

| Что сделали | Как отменить |
|---|---|
| Изменили анимации / частоту экрана / ограничение процессов | Главная → Твики → «Сбросить» у этого твика |
| Заморозили приложение | Приложения → Управление → «Замороженные» → приложение → «Разморозить» |
| Удалили системное приложение | Приложения → Управление → «Удалённые» → «Восстановить» |
| Отправили в песочницу | Песочница → приложение → «Убрать из песочницы» |
| Отсортировали файлы | Файлы → Сортировка → «Журнал операций» → «Откатить» |
| Сломали разрешение / DPI экрана командой | Терминал → Команды → Дисплей → «Сбросить разрешение и DPI» |

**Если что-то пошло совсем не так:**
- Удаление UltraCore **не отменяет** сделанные изменения (замороженные приложения останутся замороженными). Поэтому сначала верните изменения, потом удаляйте.
- Заморозить что-то критичное нельзя (защита 🛡), но если телефон ведёт себя странно после заморозки — разморозьте последние замороженные приложения.
- Крайний случай: сброс телефона к заводским настройкам возвращает все системные приложения.

## 13. Частые вопросы и проблемы

**«Shizuku: Не запущен» после перезагрузки.**
Это нормально. Откройте Shizuku → «Запустить». Нужны включённые Wi-Fi и «Отладка по Wi-Fi».

**«Подключение…» висит дольше 15 секунд.**
Нажмите «Подключить» в карточке состояния. Если не помогло — перезапустите Shizuku (остановить → запустить).

**Многие пункты 🔒 с подсказкой про ограничения отладки.**
Прошивка блокирует команды отладки. Xiaomi / Redmi / POCO — включите «Отладка по USB (настройки безопасности)». Samsung — проверьте «Автоблокировщик». Другие производители — поищите похожие переключатели в «Параметрах разработчика» и в разделе безопасности. После изменения нажмите 🔄 на «Обзоре».

**Твик частоты экрана показывает жёлтое сообщение.**
Ваша прошивка управляет частотой своей настройкой. Выберите режим в системных настройках «Дисплей» → «Плавность движений» / «Частота обновления».

**«Циклы зарядки» = 0.**
Некоторые прошивки не сообщают это значение стандартным способом. Загляните в «Дополнительные данные от прошивки» — число может быть там под другим названием.

**Экран в «Экранах» помечен 🔒.**
Приложение закрыло этот экран от запуска снаружи. Без Root Android его открыть не позволит — это ограничение системы, а не UltraCore.

**Песочница не замораживает приложение после выключения экрана.**
Разрешите уведомление песочницы и отключите экономию батареи для UltraCore **и** Shizuku. На некоторых телефонах нужно ещё разрешить «Автозапуск» или «Работу в фоне» в настройках приложения.

**Установка APK завершилась ошибкой.**
Прочитайте причину в отчёте. «Система запретила откат версии» — нельзя установить более старую версию без Root. Если установка блокируется прошивкой — попробуйте опцию «Указать установщик Google Play».

**Ярлык на рабочем столе не открывается.**
Удалите ярлык и создайте заново (после некоторых обновлений UltraCore старые ярлыки перестают работать — так защищены ярлыки от подделки).

**Где лежат бэкапы APK?**
Во внутренней памяти: папка `Download/UltraCore/Backups`.

**Сборка в GitHub Actions упала / не могу найти APK.**
Откройте последнюю сборку с зелёной галочкой ✅. Если все красные — скопируйте последние ~50 строк лога упавшего шага и сообщите автору.

## 14. Словарик

| Слово | Что значит |
|---|---|
| **Shizuku** | Приложение-посредник, которое даёт другим приложениям права «отладки», как у подключённого компьютера |
| **ADB** | Android Debug Bridge — инструмент отладки Android. Режим «ADB, без Root» — обычный режим работы |
| **Root** | Полный доступ к системе (требует взлома телефона). UltraCore без него работает, но часть функций 🔒 |
| **Заморозка** | Выключение приложения без удаления. Оно не работает и не видно, пока не разморозите |
| **Удаление для пользователя** | Системное приложение скрывается и отключается у вас, но его файл остаётся в системе — можно вернуть |
| **APK / APKS** | Файл установки Android-приложения / архив из нескольких таких файлов |
| **Activity (экран)** | Отдельный экран приложения |
| **Пакет** | Внутреннее имя приложения, например `com.android.chrome` |
| **Кэш** | Временные данные приложений; удалять безопасно, они создаются заново |
| **Макрос** | Набор команд, которые выполняются по очереди одной кнопкой |
| **Песочница** | Режим, в котором приложение заморожено всё время, кроме моментов, когда вы им пользуетесь |
| **Dry Run / Предпросмотр** | Показ того, что будет сделано, без реальных изменений |
